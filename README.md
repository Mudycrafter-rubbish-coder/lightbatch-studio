# LightBatch Studio

Official product page for LightBatch Studio 1.0.

LightBatch Studio applies one photographic treatment to a batch of similarly lit
photos using 16 local sliders, live Before/After preview, presets, and
collision-safe export.

The free trial is published under Releases. The trial exports up to 20 images
per batch.

Official site: https://mudycrafter-rubbish-coder.github.io/lightbatch-studio/
