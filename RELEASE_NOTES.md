# LightBatch Studio 1.0.0

The first public trial includes:

- 16 photographic adjustment sliders
- live Before/After preview
- automatic white balance
- six built-in starter presets
- custom JSON preset save/load
- batch processing for JPEG, PNG, WebP, BMP, and TIFF
- JPEG, PNG, WebP, or source-format export
- quality, maximum-edge, filename suffix, and metadata controls
- collision-safe output names
- a JSON batch manifest

The trial includes every feature and up to 20 source images per batch.
